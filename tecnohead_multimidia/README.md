# TecnoHead Multimídia

App Home Assistant multiambiente para cenas Cinema, TV e Desligar Multimídia.

O App usa Ingress, API oficial do Home Assistant, MQTT Discovery e entidades `remote` selecionadas por área. O projetor é controlado somente por `remote.send_command`; não há driver BroadLink LAN, IP ou MAC.

Consulte a documentação no repositório: `README.md`, `INSTALL.md` e `docs/`.
