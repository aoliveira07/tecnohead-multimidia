# Release notes 1.2.2

Esta release corrige o empacotamento do App para o layout atual de repositório Home Assistant, além da conexão MQTT segura corrigida na versão anterior. O BroadLink existente continua sendo responsabilidade da integração do Home Assistant; o App não fala diretamente com o equipamento.

Antes de marcar a instalação como homologada, o instalador deve executar o checklist físico de [TEST_PLAN.md](docs/TEST_PLAN.md), registrar a versão instalada e anexar capturas reais. Sem acesso ao HAOS e aos equipamentos, a release deve ser tratada como instalável e parcialmente testada.
